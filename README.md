# Шепоток

Сюжетная top-down игра на Vue, PixiJS и Vite. Тигран Полосов ищет гадалку, исследует большой лес и решает, что делать с находкой. В игре пять концовок, включая секрет колодца. Открытые концовки сохраняются в галерее главного меню.

## Запуск

Установите Node.js 22 LTS (или совместимую версию 20.19+). В терминале из папки проекта:

```bash
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite. В Windows можно также запустить `Играть.bat`: он использует установленный Node.js или локальную копию в `.runtime`, если она есть.

Проверки перед изменениями и отправкой в GitHub:

```bash
npm test
npm run build
```

## Устройство проекта

- `src/App.vue` — связывает экраны и игровой контроллер; `src/components/` содержит элементы интерфейса.
- `src/game/useGame.js` управляет состоянием, вводом и жизненным циклом игры. Правила, карты, сохранения, звук, тексты и подсказки вынесены в соседние модули `src/game/`.
- `src/styles/` — стили по экранам и игровым элементам; `public/assets/` — используемые ресурсы и лицензии.
- `tests/` — тесты игровой логики на встроенном тестовом раннере Node.js. CI выполняет тесты и сборку при push и pull request.

При добавлении игровой механики по возможности держите правила в отдельном модуле без зависимости от Vue и покрывайте их тестами. Формат сохранений нужно менять с учётом старых данных: проверка и совместимость находятся в `src/game/storage.js` и `useGame.js`. Собранные файлы, зависимости, локальные исходники сторонних наборов и временные результаты проверок не входят в Git.

Управление: WASD или стрелки — ходьба; E, пробел или Enter — взаимодействие и продолжение диалога; Q — копать в лесу после получения лопаты. На сенсорном экране доступны экранные кнопки. Прогресс сохраняется в браузере. После мухомора изображение меняет цвета и мигает; системная настройка уменьшения движения отключает анимацию.

## Музыка и сохранения

В меню играет [Apex Festival Ascent](https://budgetpixel.com/background-music/apex-festival-ascent-5733becc), в лесу — [Dappled Forest Drift](https://budgetpixel.com/background-music/dappled-forest-drift-9ac59091), во время слежки — [Epic Melodic Dubstep Drop](https://budgetpixel.com/background-music/melodic-dubstep-epic-synth-led-heavy-8f21585d); все три — BudgetPixel AI, CC BY 4.0. Треки зациклены. Полные сведения о музыке и изменениях — в `public/assets/MUSIC-CREDITS.txt`.

Кнопка «Продолжить» открывает автосохранение. Во время игры кнопки «Сохранить» и «Загрузить» открывают пять отдельных слотов; они не перезаписывают автосохранение. При загрузке во время слежки, проникновения в особняк или хоровода испытание начинается с безопасной точки, а уже завершённые поручения и состояние клада сохраняются. Сохранения находятся в браузере на этом устройстве.

## Достижения и колодец

В главном меню есть галерея достижений; они сохраняются отдельно от игровых слотов и не пропадают при начале новой игры. После вступления в общество можно поговорить с человеком у колодца. В его викторине три вопроса: на каждый даётся 25 секунд, неправильный ответ или истекшее время приводят к концовке водолаза. Прогресс вопроса сохраняется при перезагрузке.

Гадалка разрешает взять лопату во время первого разговора. Если забрать её заранее, гадалка откажется помогать и её шепоток перестанет работать; у Тиграна останутся другие пути. Тайник отмечен крестиком на фотографии, которую можно открыть в лесу клавишей F. Для достижения «Ненаход» нужно получить разрешение и фотографию, а затем пять раз копнуть мимо тайника. В лесу также спрятан заброшенный лагерь.


Интерьеры дома: [Roguelike Indoor pack](https://opengameart.org/content/roguelike-indoor-pack) от Kenney, CC0; лицензия — public/assets/INDOOR-LICENSE.txt.

В инвентаре шесть ячеек: выбирайте их мышью или клавишами 1–6. Тряпку в ванной можно подобрать и использовать для необязательного задания у питбайка рядом с домом; состояние задания сохраняется вместе с игрой.
